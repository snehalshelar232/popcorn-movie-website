# Popcorn - Movie & Web Series Discovery Website

Popcorn is a movie and web series discovery website that I built as a web development project.

I created this project to practice and improve my understanding of HTML, CSS and JavaScript while also learning how to work with APIs and make a website interactive.

The website uses the TMDB API to display movie and web series information.

## Live Website

[Visit Popcorn](https://snehalshelar232.github.io/popcorn-movie-website/)

## Features

- Browse popular movies
- Browse popular web series
- Search for movies and web series
- Filter movies and series by genre
- View ratings and release dates
- View movie and series details
- Watch available trailers
- Add movies and web series to favorites
- Save favorites using LocalStorage
- Dark and light mode
- Responsive design
- Interactive movie and series cards

## Technologies I Used

- HTML5
- CSS3
- JavaScript

- LocalStorage

## About the Project

I wanted to build something more practical instead of just creating small HTML, CSS or JavaScript exercises.

So I decided to create a movie discovery website where I could use different web development concepts together.

While working on Popcorn, I practiced things like:

- Creating and structuring webpages with HTML
- Designing the website using CSS
- Making the website interactive using JavaScript
- Fetching data from an external API
- Working with JSON data
- Creating search and genre filters
- Using event listeners
- Working with LocalStorage
- Creating popups for movie details and trailers
- Creating a separate web series section
- Using GitHub for version control
- Deploying the website using GitHub Pages
